## Things 3 (unofficial) – Add Task Extension

This extension is not official and is not affiliated with Cultured Code or the Things app.

### Requirements

- macOS with Things 3 installed (uses the `things:///` URL scheme)
- Chrome (or another Chromium-based browser)

### Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this folder

### Usage

- Click the extension button to create a Things task from the current tab (title + link in notes).
- Right-click a link or selected text and choose **Add link to Things** / **Add selection to Things**.

### Privacy

This extension makes no network requests and does not collect or store your data. It only opens a `things:///add` URL to create the task in Things.
